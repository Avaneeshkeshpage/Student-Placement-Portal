# Student Placement Portal

A Java and MySQL based application for managing student placement activities.

## Technologies Used
- Java
- JDBC
- MySQL

## Features
- Add Student
- Add Company
- View Students
- Check Placement Eligibility

## How to Run
1. Download the project.
2. Add MySQL Connector/J.
3. Execute database.sql in MySQL.
4. Run PlacementPortal.java.
